# 광남고 세포분열 탐구 학습지

고등학생의 50분 CELL 시뮬레이션 수업을 위한 학생용 자료입니다. 관찰표 중심 A안으로 제작했습니다.

- [학생용 PDF](광남고_세포분열_탐구_학습지_학생용.pdf): A4, 본문 6쪽 + 앞뒤 표지 2쪽. Pretendard 글꼴 포함, 목차와 단원 칩의 내부 이동 링크 포함.
- [펼침면 미리보기](광남고_학습지_펼침면_미리보기.png): 2–3쪽, 4–5쪽, 6–7쪽 순서.
- [재편집 원본 ZIP](광남고_학습지_재편집_원본.zip): 생성 코드, 글꼴·라이선스, 승인된 로고, 확정 제작 지침, 페이지별 이미지와 검사 기록.

학교 프린터용으로 도련과 재단선을 넣지 않았습니다. 인쇄 시 A4·실제 크기(100%)를 선택하세요. 양면 출력 시 긴 쪽으로 넘기면 펼침면의 왼쪽은 짝수 쪽, 오른쪽은 홀수 쪽이 됩니다.

교사용 답안과 미제공 판권 연락처는 사용자 요청으로 제외했습니다. 기존 시뮬레이션 설명을 관찰 항목으로 줄였으며, 방추사 보기 설정 해석·염색체 수와 DNA량 비교·교차 탐구·마무리 질문은 수업용으로 새로 작성했습니다.
