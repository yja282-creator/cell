# CELL — 세포분열 실험실

체세포분열과 감수분열을 단계별 SVG 애니메이션으로 관찰하는 한국어 웹 시뮬레이션입니다. 프레임워크, 외부 API, 런타임 패키지 설치가 필요 없으며 모든 화면 자산을 저장소에서 제공합니다.

## 실행

Python 3와 웹 브라우저가 필요합니다. 저장소 디렉터리에서 실행하세요.

```sh
python3 -m http.server 5173 --bind 0.0.0.0
```

Node.js/npm이 있다면 `npm start`도 같은 서버를 실행합니다. 브라우저에서 서버의 5173 포트를 열면 됩니다. ES 모듈을 사용하므로 HTML 파일을 직접 여는 대신 HTTP 서버로 실행하세요.

## 사용

- 체세포분열 / 감수분열 탭으로 관찰할 분열을 선택합니다.
- 타임라인에서 단계를 선택하거나 이전·다음 버튼으로 이동합니다.
- 재생·일시정지, 0.5× / 1× / 2× 속도, 단계 내 진행률 슬라이더로 움직임을 제어합니다. 단계 하나는 기본 7초이며 마지막 단계에서 멈춥니다.
- 방추사·구조 이름·교차 표현을 켜거나 끌 수 있습니다. 교차 설정은 감수분열에서 표시됩니다.
- 모계·부계 염색체는 파랑·주황, 방추사는 연두, 동원체는 짙은 녹색입니다. 긴 쌍과 짧은 쌍으로 두 상동 염색체 쌍을 구분합니다.
- 키보드로 버튼과 슬라이더를 조작할 수 있고, 탭에서 방향키·Home·End도 지원합니다. 화면 크기에 따라 모바일 레이아웃으로 전환합니다.

## 생물학적 범위

동물세포 `2n=4`의 개념 모형입니다. 간기는 분열기 이전의 준비 단계로 포함했습니다. 전중기는 전기에 묶어 핵막 해체와 방추사 부착을 보여줍니다. 말기와 세포질분열은 실제로 겹칠 수 있지만 학습을 위해 별도 단계로 표시합니다.

| 과정 | 분리되는 구조 | 결과 |
| --- | --- | --- |
| 체세포분열 | 자매 염색분체 | 2n, 2C 딸세포 2개 |
| 감수 I | 상동 염색체 | n, 2C 세포 2개 |
| 감수 II | 자매 염색분체 | n, 1C 딸세포 4개 |

염색체는 동원체 수로 셉니다. S기에는 염색체 수가 유지되면서 DNA량만 2C에서 4C로 증가합니다. 후기에는 분리된 염색분체를 독립된 염색체로 세므로 한 세포의 일시적인 수와 극당 수를 구분해 표시합니다. C는 반수체 유전체의 DNA량입니다.

교차는 감수 I 전기의 긴 상동 염색체 한 쌍에서 비자매 염색분체 사이의 상호 구간 교환으로 나타냅니다. 짧은 염색체 쌍은 긴 쌍과 반대 부모 방향으로 배열해 독립분리의 한 가지 결과를 보여줍니다. 가능한 모든 교차 위치나 무작위 조합을 생성하는 모형은 아닙니다. 감수 I 말기의 핵막 재형성은 생물마다 다르며, 여기서는 형성되는 경우를 표현합니다. 난자 형성의 불균등 세포질분열, 식물의 세포판 형성, 분자 수준의 동원체 구조와 체크포인트는 생략했습니다. 길이·속도·시간은 실제 비율이 아닙니다.

개념 참고: [OpenStax Biology 2e — The Cell Cycle](https://openstax.org/books/biology-2e/pages/10-2-the-cell-cycle), [The Process of Meiosis](https://openstax.org/books/biology-2e/pages/11-1-the-process-of-meiosis).

## 검증

Node.js 18 이상에서 분리·염색체 수·단계 순서에 대한 7개 모델 테스트를 실행합니다.

```sh
npm test
# 또는
node tests/model.test.js
```

실제 Chromium에서 17개 단계와 재생, 속도, 슬라이더, 보기 설정, 모바일을 검사하는 별도 스모크 테스트도 있습니다. Python Playwright와 Chromium이 필요합니다.

```sh
python3 -m pip install playwright
python3 -m playwright install chromium
python3 tests/browser_smoke.py
```

시스템 Chromium이 있으면 자동으로 사용합니다. `CHROMIUM_PATH`로 브라우저 실행 파일을 지정할 수 있습니다. 테스트 서버는 임의의 로컬 포트에서 시작하고 완료 시 종료합니다.

## 파일

- `index.html`, `style.css`: 화면과 반응형 스타일
- `model.js`: 단계별 생물학 설명과 분리 모형
- `app.js`: SVG 렌더링, 애니메이션, 조작
- `tests/`: 모델 테스트와 브라우저 검증

별도 빌드 과정이나 비밀키는 필요 없습니다.
